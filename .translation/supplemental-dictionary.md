# Kural terimleri çeviri sözlüğü

Bu dosyada [asıl çeviri sözlüğüne](./dictionary.md) ek olarak bu kurallar için oluşturulmuş
terimlerin çeviri sözlüğü bulunur.

| İngilizce              | Türkçe       | Açıklamalar                                    |
| ---------------------- | ------------ | ---------------------------------------------- |
| House rule             | Özel kural   | buradaki kurallar                              |
| Rules as written (RAW) | Kitap kuralı | Orijinal kitaplarda yazılı kurallar            |
| Pain                   | Eziyet       | No pain no gain kuralındaki saatin adı         |
| Pawn shop              | Tefeci       | Liquidating stash kuralındaki tayfa istikhakı  |
| Swindler               | Üçkağıtçı    | Liquidating stash kuralındaki kaypak hüneri    |
| Agent                  | Aracı        | Liquidating stash kuralındaki simsar istikhakı |

## Özel isimler

Bu isimler çevrilmez, olduğu gibi aktarılır. Okunuşuna göre kesme işareti ile ek alır.
Örnek: `Deep Cuts'ın ilk versiyonunda…`

| ------------------ |
| Blades in the Dark |
| Deep Cuts          |
